# Исходные данные MVP

Синтетический набор версии 3: один бизнес, 5 черновиков разной полноты, 5 опубликованных карточек, 5 команд и 5 откликов. Все сведения, включая рабочий контакт example.com, вымышлены и не созданы AI. Персональные и чувствительные признаки участников отсутствуют. Упомянутые материалы вымышленных заказчиков не приложены; интерактивные прототипы используют собственные небольшие тестовые наборы и не изображают выполненные результаты команд.

## Форматы и загрузка

[source-data.json](source-data.json) — основной источник приложения. [source-data.csv](source-data.csv) содержит те же 21 запись; ниже приведены их полные JSON-представления. `schemaVersion: 3`, `scoringVersion: 2`. Черновики и опубликованные карточки содержат все 11 полей рейтинга, неизвестные значения — null.

CSV: UTF-8, запятая, стандартное экранирование двойных кавычек. `entity_type` = business / draft / task / team / proposal соответствует коллекциям businesses / drafts / tasks / teams / proposals. `schemaVersion` равен 3, при восстановлении выносится в корень. Пустая ячейка означает неприменимое поле; `null` — неизвестное значение. `scoringVersion`, `readinessScore`, `schemaVersion` — целые; `confirmed` — boolean. `skills`, `technologies`, `plan`, `questions`, `answers` — JSON-массивы, остальные значения — строки. Даты — ISO 8601 UTC или null. Использовать CSV-парсер, не split(','). После восстановления типизированные записи должны совпасть с JSON.

Seed загружается только при отсутствии сохранения. Приложение объединяет drafts и tasks, сохраняя id, остальные коллекции переносит целиком; results первоначально пуст. Черновики не подтверждены и не попадают в каталог; published-карточки подтверждены вымышленным бизнесом. У всех decisionFinalizedAt=null, отклики submitted, баллы команд — 0.

Сохранение `nomadex-state-v2` переносится в `nomadex-state-v3` после строгой проверки. Новые поля пользовательских данных остаются null, рейтинг пересчитывается, подтверждение черновиков снимается. Тексты, публикации, отклики, решения и результаты сохраняются; исходный ключ остаётся резервной копией. Повреждённый объект не перезаписывается. Обновлённый seed не подмешивается в существующие данные.

## Рейтинг и каталог

| Критерий | Поля | Баллы |
|---|---|---:|
| Контекст и потребность | problemContext + need | 20 |
| Данные и материалы | resources | 20 |
| Ожидаемый результат | expectedResult | 15 |
| Критерии успеха | acceptanceCriteria | 15 |
| Ограничения | scope + timingConstraints | 10 |
| Пользователи | users | 10 |
| Связь с бизнесом | businessContact + interactionFormat + feedbackProcess | 10 |

Вес группы начисляется целиком, если все её поля известны после нормализации. Неизвестность («не знаю», пробелы, null) не даёт баллов. Явное отсутствие данных или дедлайна — известное условие. До ручного подтверждения бизнесом это предварительный расчёт, после — подтверждённый рейтинг. Правка снимает подтверждение. AI не выставляет баллы; заполненность не гарантирует достоверность.

Уровни: 0–39 — «Черновик — требует уточнения», 40–69 — «Рабочая», 70–89 — «Готовая», 90–100 — «Приоритетная». Последний уровень выделен в каталоге. Уровень «Черновик» у опубликованной задачи не означает скрытый статус draft: такая карточка доступна всем командам.

| Запись | Рейтинг | Состояние |
|---|---:|---|
| task-draft-001 | 20 | Предварительно |
| task-draft-002 | 45 | Предварительно |
| task-draft-003 | 65 | Предварительно |
| task-draft-004 | 70 | Предварительно |

| task-003 | 70 | Подтверждено |

| task-005 | 15 | Подтверждено |

Каталог сортируется по рейтингу ↓, дате публикации ↓, id ↑. Фильтры темы и уровня комбинируются, сброс возвращает все публикации. Низкий рейтинг не запрещает публикацию или отклик.

## Ссылки на прототипы

Пять откликов ссылаются на поставляемую страницу `public/prototypes/demo.html`, которая работает при запуске приложения. Параметр example выбирает requests (создание заявки и смена статуса), stock (порог остатков), knowledge (поиск инструкций), booking (запись на время) или feedback (фильтр отзывов). Первые два предложения показывают один прототип заявок как альтернативные подходы к общей задаче. Изменения примеров действуют до перезагрузки. Для реальных откликов принимается HTTP(S)-ссылка без учётных данных; локальные адреса разрешены только для этих пяти примеров. Старые ссылки source-data.md#proposal-* из сохранений остаются привязаны к описанию предложения, новые ссылки на них не создаются.
